# Diagrams

Yours: a scratchpad for sequence diagrams, draw.io files and anything else still in
progress.

- **Everything here is a draft.** When a diagram is done, upload it to the feature
  issue that uses it. The copy on the issue is the one that counts.
- **No agent reads or touches this folder.** `.claude/settings.json` denies Claude's
  file tools access to it, and every agent's instructions say the same.
- **The releaser never documents from here.** It builds `Documentation/Design/` from
  the issues and their attachments.
